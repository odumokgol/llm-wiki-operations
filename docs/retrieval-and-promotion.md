# Retrieval and Promotion

## Retrieval

Start with the smallest context that can answer the question:

1. Read the schema only when rules affect the answer or an edit.
2. Read the index and Home/Hot dashboards.
3. Route through the topic map and Context Bundle.
4. Expand to the project hub or decision page.
5. Read concepts, entities, comparisons, and queries.
6. Open raw evidence when a claim, number, date, quote, or contradiction needs verification.

## Answer quality

A grounded answer should:

- distinguish direct evidence from interpretation;
- cite the relevant Wiki pages or source paths;
- state uncertainty and missing confirmation;
- avoid mixing projects, profiles, or personal contexts;
- file substantial reusable answers as Query or Comparison pages only when worth re-deriving.

## Promotion decision

Before promoting a query, ask:

- Is it repeated or likely to be reused?
- Is the evidence strong enough?
- Does an existing page already cover it?
- Does it change an active project or decision?
- What is the smallest durable page type?

Promotion is not deletion. The original query and source remain evidence.
